# 先古之民额外选项

角色选择页的金黄色“更多设置”按钮打开 RitsuLib 的能天使设置页。先古设置统一放在一个初始折叠的“先古之民额外选项”分区内：总开关、拉特兰/企鹅物流各自的出现方式、按需显示的概率滑块，以及恢复默认。社区统计保留为同页独立分区，恢复先古默认值不会改变上传授权。

配置用于下一局，适用于普通、自定义与多人模式；不重新抽选现有局或读档中的先古。拉特兰仍属于 Hive，企鹅物流仍属于 Glory，设置不会把它们塞入原先不适用的幕或绕过候选资格检查。

默认模式不重设候选和权重：无其他修改时，沿用原版等权抽选及 Darv 的共享先古入池规则；其他模组已提供加权抽选时，直接执行原来的加权调用和权重函数，不额外消耗随机数。设置为禁止/必定/自定义概率后，才改变本 Mod 先古的权重；不会添加缺席的候选，不改其他先古之间的相对权重，也不把它们原本的零权重改为正数。

若目标概率为 `p`，其他候选权重之和为 `S`，则本 Mod 目标权重为 `p*S/(1-p)`；0%排除目标，100%仅保留目标。另一模组若把本 Mod 的两位先古放在同一池，则同时处理两位的设置：可满足的概率共用剩余权重；请求合计达到100%时按请求比例分配；多个“必定出现”之间等分。这只处理数学上不能同时满足的冲突，常规第二/三幕彼此独立。

补丁仅包装 `ActModel.GenerateRooms` 内一个可识别的 `Rng.NextItem<AncientEventModel>` 或 `WeightedNextItem<AncientEventModel>` 调用，并尽量在其他 transpiler 之后运行。另一个模组若完全替换这段抽选、出现多个抽选调用或绕过此方法，本 Mod 保留其实现并记录提示；这时额外选项可能无法作用于它，不阻断该模组加载。不能据此承诺任意第三方补丁组合都兼容。

本地选项存于 `user://AK_Exusiai/ancients.json`。开局通过 RitsuLib `RunSavedData` 的共享槽 `ancientAppearance` 捕获房主配置，随开局消息传给客机并进入存档；客机贡献不能覆盖共享槽，客机本地偏好不参与本局抽选。缺少快照的额外生成入口沿用原有抽选，不回退到客机本地设置。

逻辑回归：

```powershell
dotnet run --project tests/AncientSettings/AncientSettingsTests.csproj /p:RunPckExport=false /p:CopyModOnBuild=false
```

覆盖默认种子序列、0/100%与中间概率、不等权第三方候选、原有零权重、混合先古池、房主数据传输/客机写入拒绝、读档与补丁调用点检查。双端真实联机和任意第三方组合仍需实机回归。
