# 能天使控制台测试命令

所有命令都以 `exusiai` 为统一入口，并且只在战斗中生效。输入 `exusiai help` 可在控制台内查看简明帮助；命令与参数支持 Tab 补全。

## V1 可重复测试场景

```text
exusiai scenario list
exusiai scenario <场景名>
exusiai scenario <场景名> upgraded
```

`scenario` 会建立隔离的战斗夹具：准确设置为 100 能量，移除当前战斗牌堆中的所有卡牌副本及双方现有的 AK_Exusiai 能力，再按场景创建手牌、抽牌堆、弃牌堆、弹药和必要的敌人减益。它不会修改玩家的局内永久牌组；建议在专门的测试战斗中使用，不要在需要保留当前战斗进度时使用。升级参数只升级场景中可升级的牌。

| 场景 | 初始状态 | 核心验收点 |
| --- | --- | --- |
| `ammo-partial` | 5 弹药；天空大扫除、扫射模式、拉特兰欢迎你 | 每次只测试一张并重新建立场景。8 段攻击只有前 5 个实际执行段增伤且共消耗 5 弹药；AOE 同一段只消耗 1 发。 |
| `ammo-snapshot` | 16 弹药；天空大扫除、冲锋模式 | 无其他修正时，基础天空大扫除造成 `(2+3)×8=40`，消耗 8 发后剩 8 发；跨过 15/10 阈值不会降低同一张牌后续段的 `+3` 快照。 |
| `ammo-multipliers` | 10 弹药；双发套件、帕格尼尼定制、弹幕嗨破天、激光炮、勿忘我 | 双发与帕格尼尼进入同一加算倍率区；先古牌倍率独立；激光炮和勿忘我按实际支付的全部弹药逐发累加。测试不同攻击前应重建场景。 |
| `overload` | 30 弹药并自动进入过载；手牌含易燃易爆、开火成瘾症、激光炮、勿忘我、派对时间；弃牌堆恰有 5 张攻击 | 过载期间弹药始终保持 30 且无法继续获得；开火成瘾症对准备好的 5 张攻击使用 5 发预付加成，激光炮/勿忘我使用 30 发加成，派对时间第 31 段以后也不丢失增伤。 |
| `explosive` | 10 弹药；3 张爆弹和单段、多段、AOE 攻击各一张 | 每张爆弹搭配一种攻击。追加伤害只结算一次，数值为该牌对所有目标造成的总实际伤害的 50%；多层爆弹依次作用于后续多张攻击，每张消耗 1 层。 |
| `angel` | 10 张手牌，包括告解、共感形态、虔心十字、能天使打击、回望来路、笨拙与受伤；抽牌堆 3 张普通牌 | 打出共感形态并进入下一回合，选择一张手牌添加天使（已有天使也可刷新），随后每打出一张天使牌应只抽 1 张牌。诅咒获得天使会立即消耗，状态牌不会；另用 `exusiai angel <索引>` 检查免费资格刷新。 |
| `angel-x-empathy` | 共感形态、压满弹匣！、能天使打击；100 能量 | 打出共感形态并进入下一回合，给压满弹匣！添加天使。X 费牌仍须支付全部剩余能量并正常生效；每张天使牌只触发一次抽牌，不产生递归重放。 |
| `interference` | 首名敌人为干扰 10、沉默 0；包含全部新干扰测试牌 | 执行 `exusiai interference 0 6` 后必须变为干扰 16、沉默 2；干扰减伤最高 50%，干扰打击按同一目标层数增加段数，瞄准弱点获得火力，天赋只放大玩家对该敌人的伤害。 |
| `new-cards` | 10 弹药、首名敌人干扰 5；九张 V1/V1.2 新增或重做牌 | 依次检查星标手牌升级、干扰体系、铳弹协约即时弹药、虔诚从抽牌堆添加天使、混乱狂飙抽2（3）张后将歧途加入弃牌堆，以及歧途仅在消耗或战斗中变化时扣减力量与敏捷。 |

`exusiai test` 是 `exusiai scenario` 的等价别名。场景命令返回的信息中也会直接显示该场景的核心验收点。

## 状态观察与精确注入

```text
exusiai state
exusiai angel 0
exusiai interference 0 6
```

- `state` 显示玩家生命、能量、弹药、当前每发实际增伤、所有能力，以及每名存活敌人的索引、生命、干扰、沉默和能力。
- `angel` 为指定手牌给予天使；已有天使时刷新首次免费资格。目标为诅咒时会立即消耗，状态牌不会。
- `interference` 为指定敌人增加 1–100 层干扰，并通过正式的 `InterferenceCmd` 结算跨越的所有沉默阈值。

## 新遗物快递/中转体系测试

```text
exusiai logic
exusiai logic transit
exusiai logic upgraded
exusiai logic transit upgraded
```

- 将当前能量准确设置为 100。
- 生成测试牌前，先通过原版整手弃牌流程把当前手牌全部放进弃牌堆，并正常处理弃牌动画与相关 Hook；不会把原手牌从本场战斗中删除。
- 不带分组参数时生成 10 张与新遗物快递有关的测试牌；使用 `transit` 时生成其余 6 张以获得中转遗物为主的测试牌。
- 每组都不超过 10 张手牌上限。使用 `upgraded` 时生成该组的全部升级版；参数顺序可以互换。
- `delivery`/`1` 是默认快递组的显式写法，`transit`/`2` 是中转组的写法。
- `exusiai logistics` 是 `exusiai logic` 的等价别名。

默认快递组：暴力运输、免费派送、企鹅特快、企鹅标快、企鹅跨境、企鹅大件、使命必达！、加急！、物流外包、货如轮转。

中转组：武装护送、“主”的庇佑、行动开始！、企鹅中转站、包裹、愿主同在。

代码还会在执行弃牌前检查所选分组数量；以后向测试组添加卡牌时，如果超过当前手牌上限，命令会拒绝执行并提示先拆分分组，不会把多余测试牌塞入弃牌堆或制造 UI 溢出。

## 查看手牌索引与状态

```text
exusiai hand
```

输出当前能量、弹药，以及每张手牌的从 0 开始的索引、公开 ID、基础重放、天使和升级状态。后续针对单张手牌的命令都使用这里显示的索引。

## 添加重放

```text
exusiai replay 0 10
```

给第 0 张手牌增加 10 层基础重放。该命令是“增加”而不是“设置”；为避免误输入导致一张牌执行过多次，单张牌的基础重放总数上限为 100。

## 设置弹药

```text
exusiai ammo 22
```

将当前弹药准确设置为指定值，可用范围为 0–30。Tab 补全包含多段攻击与火力阈值测试常用的 `0/5/10/16/22/30`。

## 推荐组合

```text
exusiai logic upgraded
exusiai hand
exusiai replay 0 10
exusiai ammo 22
```

这组命令会建立升级版新遗物快递测试整手，再为其中一张牌添加重放，并准备 22 发弹药。需要测试中转牌时改用 `exusiai logic transit upgraded`；需要测试别的组合时，可先用 `exusiai hand` 重新确认手牌索引。

完成任何 `scenario` 或 `logic` 设置后，建议立即执行：

```text
exusiai hand
exusiai state
```

这样可以先记录场景基线，再打牌并重复执行 `state` 对照资源、能力和敌人层数变化。
