# AK_Exusiai 当前进度

更新：2026-11-17。这里记录**本地源码与构建结果**，不代表 Steam 工坊已上传同一构建。旧版逐次开发记录见 [2026-10-20 前进度归档](archive/PROGRESS_2026-10-20.md) 和 [早期归档](archive/PROGRESS_2026-09-10.md)。

## 当前基线

- 游戏：正式版 v0.111.1（提交 `cc1f9462`）及 public beta v0.113.1（提交 `d09d48e5`）分别构建；发布包最低游戏版本对应为 0.111.1 / 0.113.0。
- 框架：NuGet `STS2.RitsuLib.Compat.0.111.0` / `STS2.RitsuLib` 均为 0.6.14，工坊订阅运行时 0.6.14，清单最低依赖 0.6.14。发布包仅含本 Mod 的 DLL/PCK/JSON；`RitsuLibAutoCopy=false`。
- 内容：能天使角色、105 个注册卡牌模型（91 张角色卡、12 张衍生牌、2 张诅咒）、9 件角色遗物、6 瓶药水、拉特兰和企鹅物流两位先古之民及其 20 件先古遗物；六套外观和中英文文本。卡牌与遗物设计以 `docs/` 下 CSV 为准。
- 清单 `version` 仍为 1.1.0。准备正式上传时再按实际发布内容统一版本和更新说明。

## 双分支兼容适配

游戏 v0.113 移除了 `SingletonModel`、改变了战斗伤害命令、先古房间生成、角色选择、锻造选牌等 API。同一份源码以 `GameApiTarget` 条件编译两套游戏与 RitsuLib API；差异包括随从交互、遗物出现条件、诅咒变形回调、攻击间隔补丁、弹药来源，以及先古与角色选择补丁签名。研学证明仍用独立锻造选项完成至多两张选择，并随后随机升级一张剩余牌。

2026-11-17 验证：两套发布包均完成 C# 与 PCK 构建，0 警告、0 错误，目录各只有 DLL/PCK/JSON。分别在正式版与测试版游戏中临时部署后无界面启动：工坊 RitsuLib 0.6.14 选择正确兼容程序集，能天使 32/32 玩法补丁成功、内容注册与 `ModelDbDefer` 完成，且无 Mod 初始化异常。测试后已恢复原有本地 Mod 文件。测试版先古设置控制台测试通过 733 项检查。无界面启动只证明加载，尚不证明战斗与事件行为；两套包尚未上传。
