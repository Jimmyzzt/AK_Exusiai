# AK_Exusiai 当前进度

更新：2026-11-13。这里记录**本地源码与部署结果**，不代表 Steam 工坊已上传同一构建。旧版逐次开发记录见 [2026-10-20 前进度归档](archive/PROGRESS_2026-10-20.md) 和 [早期归档](archive/PROGRESS_2026-09-10.md)。

## 当前基线

- 游戏：本机 public beta v0.113.0（`release_info.json`，提交 `16ac0fe3`）；Mod 清单最低游戏版本已设为 0.113.0。
- 框架：NuGet `STS2.RitsuLib` 0.6.11，工坊订阅运行时 0.6.11，清单最低依赖 0.6.11。仅部署本 Mod 的 DLL/PCK/JSON；`RitsuLibAutoCopy=false`。
- 内容：能天使角色、105 个注册卡牌模型（91 张角色卡、12 张衍生牌、2 张诅咒）、9 件角色遗物、6 瓶药水、拉特兰和企鹅物流两位先古之民及其 20 件先古遗物；六套外观和中英文文本。卡牌与遗物设计以 `docs/` 下 CSV 为准。
- 清单 `version` 仍为 1.1.0。准备正式上传时再按实际发布内容统一版本和更新说明。

## 本次兼容适配

游戏 v0.113.0 移除了 `SingletonModel`、改变了战斗伤害命令、先古房间生成、角色选择、锻造选牌等 API。当前源码改为 RitsuLib 的 `HookedSingletonModel`，并按新签名更新 32 个玩法补丁中的受影响目标；研学证明用独立锻造选项完成至多两张选择，保留随后随机升级一张剩余牌的效果。其他迁移涉及怪物可交互性、遗物出现条件、诅咒变形回调、随机洗牌与类型重名。

2026-11-13 验证：纯 C# 与完整构建均为 0 警告、0 错误；Godot 导出并部署 PCK，部署 DLL/JSON 与本地输出一致。先古设置控制台测试通过 733 项检查。临时启用 Mod 的无界面启动显示 RitsuLib 初始化成功、能天使 32/32 玩法补丁成功、角色/卡牌/遗物/战斗 Hook 模型注册成功、`ModelDbDefer` 完成，且无 Mod 初始化异常。测试后已恢复原有 Mod 禁用设置。无界面启动只证明加载，尚不证明战斗与事件行为。
