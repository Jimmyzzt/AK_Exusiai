1. 弹药上限 30。达到 30 时进入过载；过载期间不能继续获得或消耗弹药，所有实际攻击段仍按进入过载时的弹药快照获得增伤。普通回合结束清空弹药并退出过载；“过载模式”允许保留剩余弹药，但仍退出过载。战斗结束清空。

3. 每张攻击牌开始结算时建立一次弹药增伤快照：`max(2, floor(消耗前弹药 / 5)) + 火力`。同一张多段牌即使消耗后跨过档位，后续仍有弹药的攻击段继续使用该快照。例如无其他增伤、16 发时打出基础 `2×8` 的天空大扫除，应造成 `(2+3)×8`，消耗 8 发并剩余 8 发。
4. 多发弹药的加成逐发/逐段累加。双发套件、帕格尼尼等属于同一加算弹药倍率区；火力电台是独立乘区；具体卡牌自己的弹药倍率也是独立乘区。完整算完后再交给游戏标准伤害流程取整。
