# V1.3 卡牌平衡性调整

本记录以 V1.2 卡表为对照，仅记录设计表发生变化的 8 张牌。括号内为升级后的效果；每项的“调整前”和“调整后”均写出该牌的完整效果，包括没有变化的部分。此处是 V1.3 设计记录，具体上线以构建和实机验证为准。

## 快递与中转

- **企鹅标快**（1费技能）
  - 调整前：选择1个遗物获得快递5。获得2个中转1（2）随机遗物。
  - 调整后：选择1个**非中转**遗物获得快递5。获得2个中转2（3）随机遗物。
- **使命必达！**（攻击）
  - 调整前：3（2）费攻击。造成5点伤害5次。选择1个快递遗物立即重新生效。消耗。
  - 调整后：3（2）费攻击。造成5点伤害5次。选择1个快递遗物立即重新生效，或选择1个中转遗物使其获得中转99。消耗。
- **加急！**（1费技能）
  - 调整前：所有快递遗物的快递层数减少1（2）。消耗。
  - 调整后：所有快递遗物的快递层数减少1。升级后，所有中转遗物获得中转1。消耗。

## 天使

- **共感形态**（3费能力）
  - 调整前：虚无（升级后移除）。在回合开始时，给1张手牌添加天使。每打出1张天使牌，抽1张牌。
  - 调整后：虚无。在回合开始时，给1（2）张手牌添加天使。

## 企鹅物流衍生牌

以下四张牌均为0费，且打出后消耗。

- **德克萨斯**
  - 调整前：不消耗弹药。对所有敌人造成2点伤害2次并给予1（2）层虚弱。消耗。
  - 调整后：不消耗弹药。对所有敌人造成2（4）点伤害2次并给予1（2）层虚弱。消耗。
- **能天使**
  - 调整前：获得3（4）弹药，回复5点生命。消耗。
  - 调整后：获得3（6）弹药，回复5点生命。消耗。
- **可颂**
  - 调整前：获得9（13）点格挡，获得15金币。消耗。
  - 调整后：获得9（13）点格挡，获得10（15）金币。消耗。
- **空**
  - 调整前：获得1点力量，给予所有敌人2（3）层虚弱。消耗。
  - 调整后：获得1（2）点力量，给予所有敌人2（3）层虚弱。消耗。
