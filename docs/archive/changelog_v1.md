# V1.2 平衡性调整

本记录以 V1.1 预发布版为对照。括号内数值为升级后的数值。

## 新增与移除

- **新增：虔诚**：1费技能。使抽牌堆中的1张牌获得天使，抽2（3）张牌。
- **新增：歧途**：无法打出的诅咒。具有保留；被消耗或在战斗中变化时，失去1点力量与敏捷。
- **新增：茫然**：1费诅咒。具有保留、悔恨和消耗。
- **移除：闪光弹**：原效果为给予所有敌人2（3）层虚弱和1层干扰并消耗；现由重做后的**福音摇滚！**承接群体减益定位。

## 卡牌重做

- **免费派送**：由“使随机（升级后自选）1个遗物获得快递1；下一张牌免费打出”重做为“抽1张牌；获得中转1（2）神秘遗物；消耗”。神秘遗物由种子决定，首次使用后揭晓；此后所有同名牌显示该遗物的名称和详情。多人模式中每名玩家分别记录，并尽量分配不同遗物。
- **铳弹协约**：由“使1（2）张手牌获得天使；结束回合；下回合开始时按手牌数获得弹药”改为“从弃牌堆取回1张牌并赋予天使；立即获得等于手牌数（升级后额外+2）的弹药；结束回合”。
- **共感形态**：由“本场战斗所有卡牌获得天使”改为“回合开始时为1张手牌添加或刷新天使；每打出1张天使牌，抽1张牌”。基础版仍有虚无，升级后移除虚无。
- **福音摇滚！**：由2（1）费稀有能力“回合开始时给1张手牌添加天使”重做为1费罕见技能“给予所有敌人2（3）层虚弱和1（2）层干扰；消耗”。
- **射击技巧**：消耗弹药后的奖励由“抽2张牌”改为“对随机敌人额外造成一次等量伤害”；额外伤害不消耗弹药。
- **喧闹**：由0费“敌人已有干扰时给予1（2）层干扰”改为1费“给予1（2）层干扰；敌人原有干扰每满2层，再给予1层”。
- **天赋**：由“敌人每层干扰令其受到的伤害提高15%（25%）”改为“每层提高10%；升级后打出时先给予所有敌人1层干扰”。
- **瞄准弱点！**：费用由0提高至1；触发条件由“有干扰的敌人”扩大为“任意有负面状态的敌人”，仍获得2（3）点火力。
- **前路何在？**：由“造成12点伤害3（4）次，并将疑虑加入手牌”改为“造成8（10）点伤害3次，并将茫然加入手牌”。
- **混乱狂飙**：由“抽3（4）张牌，将孢子心灵加入手牌”改为“抽2（3）张牌，将歧途加入弃牌堆”。

## 攻击牌调整

- **★**：伤害由7提高至8；升级效果仍由“升级1张手牌”变为“升级所有手牌”。
- **武装护送**：伤害由10（14）降低至8（12）；中转1开心小花不变。
- **虔心十字**：每段伤害由9（12）降低至6（9），攻击2次及为1张手牌添加天使不变。
- **摇滚！**：伤害由10（14）降低至8（10）；干扰由固定1层提高至1（2）层。
- **干扰打击**：基础伤害由12（16）降低至10（14）；按目标干扰层数增加攻击次数的机制不变。
- **改装不当**：群体每段伤害由12（14）降低至9（12）；负面牌由“将笨拙加入弃牌堆”改为“将悔恨加入手牌”。
- **以铳起誓**：伤害由30（35）降低至20（25）；天使以及生成圣城净化（+）的效果不变。
- **扫射模式**：每段伤害由13（16）降低至10（14），仍攻击4次。
- **派对时间！**：攻击次数由25次降低至15次；每段伤害2（3）及生成睡眠不佳不变。
- **愿主指引**：升级伤害由14提高至15，基础伤害11及生成圣城指引（+）不变。

## 技能与能力牌调整

- **快速弹匣**：获得弹药由2（3）提高至2（4），抽2张牌不变。
- **坚定之心**：受伤的加入位置由弃牌堆改为手牌；仍获得15（20）点格挡并加入2张受伤。
- **借贷**：债务的加入位置由弃牌堆改为抽牌堆；仍获得45（60）金币。
- **企鹅标快**：给予目标遗物的快递由7降低至5；获得2个中转1（2）随机遗物不变。
- **企鹅跨境**：给予目标遗物的快递由5降低至4；由“使1个中转遗物获得中转3（4）”改为“使1（2）个中转遗物各获得中转3”。
- **圣城怜悯**：由2费罕见调整为3（2）费稀有；格挡由10（14）调整为固定8；仍为手牌中所有非天使牌添加天使。
- **圣城威光**：天使牌计数由“不含消耗堆”改为“包含所有牌堆”。
- **圣城之拥**：费用由3降低至2；每张天使牌提供的单次格挡由5（8）提高至6（9）。
- **圣城指引**：抽牌由3（4）降低至2（3），天使与消耗不变。
- **圣城感召**：触发翱翔所需的单回合天使牌数由5张降低至3张；升级仍使费用降低1。
- **优秀毕业生**：在“使所有敌人的干扰翻倍（三倍）”之后，新增给予所有敌人1层干扰。
- **圣徒行记**：费用由1提高至2（1）；永久成长由每次1（2）点统一为每次1点火力。

## 遗物调整

- **能天使的杰作**：战斗开始时的弹药由8提高至10，火力由3降低至1。
- **火力电台**：由“弹药伤害加倍，回合开始失去1弹药”重做为“同一回合内每消耗4发弹药，获得1点火力”。过载期间视为正确消耗的弹药同样计入。
- **主-主机**：效果明确为战斗中“每次”获得诅咒牌时获得1点能量，功能不变。

## 规则与界面

- 干扰由每层降低10%攻击伤害调整为每层降低5%，上限仍为50%；首次获得干扰及每额外获得5层干扰时获得沉默。
- 状态牌获得天使后不再因天使效果被消耗；诅咒牌仍会被消耗。
- 被快递的中转遗物再次获得中转时，先以中转数值抵消快递；快递降至0后的剩余数值继续增加中转。
- 大合照与大帝的珍藏现在提供“物流卡”总览及全部8张基础或升级物流卡的详情。
- 固定给予快递的卡牌新增“快递与中转”机制说明；火力、干扰、沉默等关联关键词补齐详情。
- 自定义能力图标拆分为64×64小图和256×256大图，避免能力触发闪光尺寸异常。
- 能天使能量图标改为仅作用于能天使卡池，不再影响其他角色。
- 派对时间与天空大扫除的多段攻击只播放一次角色攻击动作，并缩短派对时间的段间间隔。
