# V1.2 平衡性调整

本记录以 V1.1 版本为对照。括号内数值为升级后的数值。

## 新增与移除

- **新增：虔诚**：1费技能。使抽牌堆中的1张牌获得天使，抽2（3）张牌。
- **新增：歧途**：无法打出的诅咒。具有保留；被消耗或在战斗中变化时，失去1点力量与敏捷。
- **新增：茫然**：1费诅咒。具有悔恨和消耗。
- **移除：闪光弹**：给予所有敌人2（3）层虚弱和1层干扰，消耗。

## 卡牌调整

- **★**：伤害7 -> 8。
- **穿甲弹**：无条件给予1（2）层易伤 -> 若本次攻击消耗弹药，给予1（2）层易伤。
- **射击技巧**：消耗弹药后抽2张牌 -> 消耗弹药后对随机敌人额外造成一次等量伤害；额外伤害不消耗弹药。
- **武装护送**：伤害10（14） -> 8（12）。
- **快速弹匣**：弹药2（3） -> 2（4）。
- **虔心十字**：每段伤害9（12） -> 6（9）。
- **摇滚！**：伤害10（14） -> 8（10）；干扰1 -> 1（2）。
- **干扰打击**：伤害12（16） -> 10（14）。
- **喧闹**：0费，敌人已有干扰时给予1（2）层干扰 -> 1费，给予1（2）层干扰，敌人原有干扰每满2层，再给予1层。
- **天赋**：敌人每层干扰使其受到的伤害提高15%（25%） -> 每层提高10%；升级后打出时先给予所有敌人1层干扰。
- **瞄准弱点！**：0费，有干扰的敌人使你获得2（3）点火力 -> 1费，任意有负面状态的敌人使你获得2（3）点火力。
- **改装不当**：对所有敌人造成12（14）点伤害2次，将笨拙加入弃牌堆 -> 对所有敌人造成9（12）点伤害2次，将悔恨加入手牌。
- **以铳起誓**：伤害30（35） -> 20（25）。
- **扫射模式**：每段伤害13（16） -> 10（14）。
- **前路何在？**：造成12点伤害3（4）次，将疑虑加入手牌 -> 造成8（10）点伤害3次，将茫然加入手牌。
- **派对时间！**：攻击次数25 -> 15。
- **愿主指引**：伤害11（14） -> 11（15）。
- **免费派送**：使随机（升级后自选）1个遗物获得快递1；下一张牌免费打出 -> 抽1张牌；获得中转1（2）神秘遗物；消耗。神秘遗物由种子决定，首次使用后揭晓；此后所有同名牌显示该遗物的名称和详情。多人模式中每名玩家分别记录，并尽量分配不同遗物。
- **企鹅标快**：快递7 -> 5。
- **企鹅跨境**：快递5 -> 4；使1个中转遗物获得中转3（4） -> 使1（2）个中转遗物各获得中转3。
- **坚定之心**：将2张受伤加入弃牌堆 -> 将2张受伤加入手牌。
- **借贷**：将债务加入弃牌堆 -> 将债务加入抽牌堆。
- **福音摇滚！**：2（1）费稀有能力牌，回合开始时给1张手牌添加天使 -> 1费罕见技能牌，给予所有敌人2（3）层虚弱和1（2）层干扰，消耗。
- **圣城怜悯**：2费罕见，格挡10（14） -> 3（2）费稀有，格挡8。
- **圣城威光**：不计算消耗堆中的天使牌 -> 计算所有牌堆中的天使牌。
- **圣城之拥**：费用3 -> 2；每张天使牌提供的格挡5（8） -> 6（9）。
- **圣城指引**：抽牌3（4） -> 2（3）。
- **圣城感召**：触发翱翔所需的单回合天使牌数5 -> 3。
- **优秀毕业生**：使所有敌人的干扰翻倍（三倍） -> 使所有敌人的干扰翻倍（三倍），再给予所有敌人1层干扰。
- **圣徒行记**：费用1 -> 2（1）；永久增加火力1（2） -> 1。
- **过载模式**：回合结束时保留全部剩余弹药 -> 本回合结束时保留一半弹药。
- **铳弹协约**：使1（2）张手牌获得天使；结束回合；下回合开始时按手牌数获得弹药 -> 从弃牌堆取回1张牌并赋予天使；结束回合；下回合开始时获得等于手牌数（升级后+2）的弹药。
- **共感形态**：本场战斗所有卡牌获得天使 -> 回合开始时为1张手牌添加或刷新天使；每打出1张天使牌，抽1张牌。基础版仍有虚无，升级后移除虚无。
- **混乱狂飙**：抽3（4）张牌，将孢子心灵加入手牌 -> 抽2（3）张牌，将歧途加入弃牌堆。

## 遗物调整

- **能天使的杰作**：战斗开始时弹药8 -> 10；火力3 -> 1。
- **火力电台**：弹药伤害加倍，回合开始失去1弹药 -> 同一回合内每消耗4发弹药，获得1点火力；过载期间视为正确消耗的弹药同样计入。
- **主-主机**：描述明确为战斗中每次获得诅咒牌时获得1点能量，效果不变。

## 规则与界面

- 干扰由每层降低10%攻击伤害调整为每层降低5%，上限仍为50%；首次获得干扰及每额外获得5层干扰时获得沉默。
- 状态牌获得天使后不再因天使效果被消耗；诅咒牌仍会被消耗。
- 被快递的中转遗物再次获得中转时，先以中转数值抵消快递；快递降至0后的剩余数值继续增加中转。
- 大合照与大帝的珍藏仅保留“物流卡”说明，并在左侧展示全部8张基础或升级物流卡。
- 天使衍生牌与物流卡加入衍生牌图鉴；茫然与歧途移入“状态、诅咒、事件、任务和衍生牌”，并使用原版诅咒卡框。
- 卡牌正文不再将数字标蓝；数值蓝色仅用于侧边说明。
- 固定给予快递的卡牌新增“快递与中转”机制说明；火力、干扰、沉默等关联关键词补齐详情。
- 自定义能力图标拆分为64×64小图和256×256大图，避免能力触发闪光尺寸异常。
- 能天使能量图标改为仅作用于能天使卡池，不再影响其他角色。
- 派对时间与天空大扫除的多段攻击只播放一次角色攻击动作，并缩短派对时间的段间间隔。
