# V1.4 卡牌拟平衡性调整

主要想改善前期弹药、和重新设计部分快递卡牌，增强快递卡的强度。改动以 V1.3 （当前实装版本）为对照。

## 内容与平衡性

### 初始卡牌

- **增强「子弹上膛」**：获得弹药由 4（6）→ **5（7）**。

### 普通卡牌

- **重做「★」**：由“造成8点伤害；若本次攻击消耗弹药，升级1张（所有）手牌” → **“造成8（12）点伤害。获得中转1的开心小花。”**
- **调整「天空大扫除」**：稀有度由罕见 → **普通**。
- **调整「愿主指引」**：
  - 稀有度由罕见 → **普通**。
  - 伤害由13（16）→ **12（15）**。
- **重做「暴力运输」**：由“保留。使随机1个遗物获得快递2。造成40（52）点伤害” → **“造成20（26）点伤害。快递2：额外造成1次伤害。”** 不再保留。
- **削弱「“主”的庇佑」**：格挡由9（12）→ **8（11）**。
- **增强「快速弹匣」**：获得弹药由2（4）→ **3（5）**。
- **增强「回望来路」**：获得弹药由2（3）→ **3（4）**。
- **调整「临时改装」**：原本获得8（10）点格挡 → **改为升级1张（升级后所有）手牌**；获得2（3）点本回合火力的效果不变。
- **重做「准备万全！」**：由“获得11（13）点格挡；下回合额外获得1点能量并抽1（2）张牌” → **“获得11（14）点格挡、2（3）弹药，将1张圣城冰淇淋加入手牌。”**
- **移除「射击技巧」**。

### 罕见卡牌

- **重做「武装护送」**：
  - 稀有度由普通 → **罕见**。
  - 由“造成8（12）点伤害。获得中转1的开心小花” → **“造成10（12）点伤害。使1个中转遗物获得中转2（3）。”**
- **重做「干扰打击」**：由“造成10（14）点伤害；目标每有1层干扰，额外攻击1次” → **“造成12点伤害；目标每有1层干扰，额外造成5点伤害；给予1（2）层干扰。”**
- **增强「改装不当」**：
  - 每段伤害由9（12）→ **10（13）**，仍对所有敌人攻击2次。
  - 加入手牌的诅咒由悔恨 → **羞耻**。
- **调整「前路何在？」**：
  - 每段伤害由8（10）→ **8（9）**，仍攻击3次。
  - 新增**给予2（3）层易伤**。
- **调整「勿忘我」**：费用由3（2）→ **2**；由基础版具有保留，改为**升级后才获得保留**。
- **重做「企鹅中转站」**：由“消耗8（4）金币，成功消耗后获得中转1的随机遗物” → **“获得1点能量。快递1：再获得1（2）点能量。”**
- **重做「企鹅跨境」**：费用由1 → **0**；效果由“使1个遗物获得快递4，使1（2）个中转遗物各获得中转3” → **“将抽牌堆中的1（2）张牌放入弃牌堆。快递3：改为放入手牌。消耗。”**
- **调整「混乱狂飙」**：抽牌由2（3）→ **3**；加入弃牌堆的负面牌由始终是歧途，改为**歧途（笨拙）**。
- **增强「企鹅标快」**：使非中转遗物获得的快递由5 → **3**。
- **重做「企鹅特快」**：由“使1个遗物获得快递4；抽牌直到手牌满” → **“抽2张牌。快递2：抽牌直到手牌满。”** 升级获得保留的效果不变。
- **调整「瞄准弱点！」**：稀有度由稀有 → **罕见**。
- **增强「叉烧苹果派！」**：获得能量由3（5）→ **4（6）**。
- **新增「新世界」**（1费罕见能力）：**“（固有。）在手牌中加入1张歧途。在你的回合开始时，获得1点能量。”**

### 稀有卡牌

- **重做「企鹅大件」**：
  - 稀有度由罕见 → **稀有**。
  - 由“使1个遗物获得快递99，获得60（75）点格挡，下一回合开始时格挡不消失” → **“获得10（15）点格挡。快递5：再获得50（60）点格挡，下一回合开始时格挡不消失。”**

### 诅咒牌

- **重做「茫然」**：由**“悔恨。消耗。”** → **“你在本回合内不再能抽牌。消耗。”**
