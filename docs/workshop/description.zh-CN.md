# 子弹上膛，准备万全★

企鹅物流资深员工、苹果派物流老板能天使，前来高塔拓展业务（真的吗）。

## 支持版本

目前仅支持测试版 0.110

## 内容

- 1个新角色！
- 2组外观（能天使与新约能天使），共6套时装（能天使4套+新约能天使2套，均来自《明日方舟》官方）
- 104 张卡牌：91 张专属卡牌（含5张多人卡牌、初始与先古牌），11张衍生卡（8张企鹅物流牌、3张天使牌），2张诅咒
- 9个角色遗物，3瓶药水


## 核心机制

- **弹药**：来自天使的铳。弹药为攻击提供额外伤害。弹药越多增伤越高；弹药达到上限后进入过载，攻击力提升且不再扣除弹药，肆意倾泻火力。
- **天使**：来自拉特兰。三张天使衍生卡，提供运转。赋予卡牌天使词条，获得保留与一次免费打出。
- **企鹅物流**：来自最好的朋友们。通过快递暂时寄出遗物换取收益，再用中转调度临时遗物。大帝、德克萨斯、能天使、可颂、空、拜松、伊斯和莫斯提马也会以物流卡的形式前来支援。
- **通信技术专业**：来自她的高中。通过干扰与沉默压制敌人，每层干扰会使敌人在整场战斗攻击少许降低；首次获得干扰时给予沉默，让敌人的被动能力在本回合失效！（被动能力如敌人的力量、沙虫的吞噬、沙漏的塞凋萎、实验体的复活）
