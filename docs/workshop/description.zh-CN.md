# 能天使 · Exusiai

将《明日方舟》的能天使带入《Slay the Spire 2》：装填弹药、倾泻火力，借助天使的祝福与企鹅物流的支援攀登高塔。

## 装填，开火！

弹药为攻击提供额外伤害。安排装填与攻击的顺序，在多段射击中发挥火力；弹药达到上限后进入过载，迎来一轮爆发。

## 天使的祝福

赋予卡牌天使，获得保留与首次免费打出的机会。借助圣城衍生牌构筑连招，让下一张牌成为逆转战局的关键。

## 企鹅物流，使命必达

通过快递暂时寄出遗物换取收益，再用中转调度临时遗物。大帝、德克萨斯、能天使、可颂、空、拜松、伊斯和莫斯提马也会以物流卡的形式前来支援。

还可通过干扰与沉默压制敌人，使用多人合作卡牌为队友提供帮助。

## 包含内容

- 104 种卡牌：91 种角色卡池卡牌（含初始与先古牌）、11 种衍生牌、2 种诅咒。
- 9 件角色遗物、3 种角色药水。
- 能天使与新约能天使两组外观，共六套造型，使用同一套玩法。
- 角色动画、自定义转场、卡牌音效与光环苹果能量指示器。
- 简体中文与英文。

## 安装与兼容

需要订阅并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295)。当前开发验证基线为 Windows、游戏 public beta v0.111.0、RitsuLib 0.5.20；实际可用版本请结合条目的游戏版本范围查看。

多人游戏请保持游戏版本、Mod 版本、依赖及内容 Mod 加载顺序一致。欢迎反馈多人对局中的问题。

## 问题反馈

请在评论或 [GitHub Issues](https://github.com/Jimmyzzt/AK_Exusiai/issues) 中说明游戏与 Mod 版本、涉及卡牌及升级状态、单人/多人和复现步骤。

遇到异常请附发生问题那次运行的 `godot.log`；多人不同步请一并提供对应的 `ritsulib_state_divergence_*.zip`。游戏控制台输入 `open logs` 可打开日志目录。
