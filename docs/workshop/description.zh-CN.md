# 子弹上膛，准备万全★

企鹅物流资深员工、苹果派物流老板能天使，前来高塔拓展业务（真的吗）。

## 内容

- 1个新角色！
- 2组外观（能天使与新约能天使），共6套时装（能天使4套+新约能天使2套，均来自《明日方舟》官方）
- 104 张卡牌：91 张专属卡牌（含5张多人卡牌、初始与先古牌），11张衍生卡（8张企鹅物流牌、3张天使牌），2张诅咒
- 9个角色遗物，3瓶药水


## 核心机制

- **弹药**：来自天使的铳。弹药为攻击提供额外伤害。弹药越多增伤越高；弹药达到上限后进入过载，攻击力提升且不再扣除弹药，肆意倾泻火力。
- **天使**：来自拉特兰。三张天使衍生卡，提供运转。赋予卡牌天使词条，获得保留与一次免费打出。
- **企鹅物流**：来自最好的朋友们。通过快递暂时寄出遗物换取收益，再用中转调度临时遗物。大帝、德克萨斯、能天使、可颂、空、拜松、伊斯和莫斯提马也会以物流卡的形式前来支援。
- **通信技术专业**：来自她的高中。通过干扰与沉默压制敌人，每层干扰会使敌人在整场战斗攻击少许降低；首次获得干扰时给予沉默，让敌人的被动能力在本回合失效！（被动能力如敌人的力量、沙虫的吞噬、沙漏的塞凋萎、实验体的复活）

## V1.3 平衡性调整

以下以 V1.2 为调整前版本；括号内为升级后的数值或效果。每项均列出调整前后的完整卡牌效果。

- **企鹅标快**（1费技能）
  - 调整前：选择1个遗物获得快递5。获得2个中转1（2）随机遗物。
  - 调整后：选择1个非中转遗物获得快递5。获得2个中转2（3）随机遗物。
- **使命必达！**（攻击）
  - 调整前：3（2）费。造成5点伤害5次。选择1个快递遗物立即重新生效。消耗。
  - 调整后：3（2）费。造成5点伤害5次。选择1个快递遗物立即重新生效，或选择1个中转遗物使其获得中转99；兼有两者时按中转处理。消耗。
- **加急！**（1费技能）
  - 调整前：所有快递遗物的快递层数减少1（2）。消耗。
  - 调整后：所有快递遗物的快递层数减少1。升级后，所有中转遗物获得中转1。消耗。
- **共感形态**（3费能力）
  - 调整前：虚无（升级后移除）。在回合开始时，给1张手牌添加天使。每打出1张天使牌，抽1张牌。
  - 调整后：虚无。在回合开始时，给1（2）张手牌添加天使。
- **德克萨斯**（0费衍生攻击）
  - 调整前：不消耗弹药。对所有敌人造成2点伤害2次并给予1（2）层虚弱。消耗。
  - 调整后：不消耗弹药。对所有敌人造成2（4）点伤害2次并给予1（2）层虚弱。消耗。
- **能天使**（0费衍生技能）
  - 调整前：获得3（4）弹药，回复5点生命。消耗。
  - 调整后：获得3（6）弹药，回复5点生命。消耗。
- **可颂**（0费衍生技能）
  - 调整前：获得9（13）点格挡，获得15金币。消耗。
  - 调整后：获得9（13）点格挡，获得10（15）金币。消耗。
- **空**（0费衍生技能）
  - 调整前：获得1点力量，给予所有敌人2（3）层虚弱。消耗。
  - 调整后：获得1（2）点力量，给予所有敌人2（3）层虚弱。消耗。
