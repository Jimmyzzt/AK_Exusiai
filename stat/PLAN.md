# 能天使统计方案

更新：2026-10-07。首版已按下列范围实现，网站与 API 已部署；真实游戏对局仍待验收。

## 已确定

- 玩家同意后，只上传新增能天使局终数据；不扫描或补传历史存档。
- 首版利用游戏已有跑局记录，不额外记录出牌次数、伤害归因或专属机制计数。
- 收集并默认纳入所有 Mod 组合，记录已启用 Mod 列表；网站支持排除指定 Mod 后重新统计。
- 收集单人、联机和放弃局；默认查看单人标准局，放弃局可切换是否计作失败。
- 内容统计仅覆盖本 Mod 添加的卡牌、角色遗物和先古遗物；初始、衍生及诅咒牌也属本 Mod 内容，没有对应奖励样本时显示“不适用”。
- 只公开聚合统计，所有公开 API 和导出均不提供逐局数据或玩家标识。
- D1 和 Workers 均使用免费档位，社区统计约每15分钟更新。
- 首版指标包含总览局数、通关率、到达层数；卡牌奖励选取率、持有率、持有胜率、平均获得层数、升级/删除次数，以及各幕选取率与选择后通关率；角色及先古遗物获得/选择频次和持有胜率。每项显示样本量，支持时间、版本、进阶、人数、放弃口径及 Mod 排除筛选。
- 脱敏跑局明细和聚合数据暂不设保存期限；数据过多时再讨论处理，不预设自动清理。
- 免费额度耗尽时暂停接收上传，由客户端队列等待恢复；网站继续展示最近统计并提示更新时间。存储容量满时需另行决定处理办法，不能通过等待每日额度恢复解决；客户端队列有上限。
- 同一套网页已部署到 GitHub Pages 和 Worker，主站为 `https://exusiai.zzt.si`，两站共用 Worker 统计 API。
- 文档、网站、Worker、数据库迁移和 Mod 统计代码统一放在 `stat/`。Mod 入口仅保留必要调用；`stat/mod/` 通过显式 C# 编译项接入，网页与 Node 依赖排除于游戏构建和 PCK。
- RitsuLib 编译依赖和清单最低版本已更新到最新稳定版0.6.6，与本机工坊版本一致；纯 C# 构建0警告、0错误。所有项目均禁止复制本地运行时。

## 分幕卡牌指标口径

- **各幕选取率**：该幕奖励中选择该牌的次数 / 该幕奖励中提供该牌的次数。
- **各幕选择后通关率**：在该幕选择过该牌的玩家局中，最终通关的比例；同一玩家局在同一幕重复选择同牌只计一次。页面使用“第X幕选择后通关率”标签，与持有胜率区分。
- 胜率分母沿用当前放弃局筛选口径；没有对应奖励样本时显示“不适用”。

界面默认采用中文和“能天使数据统计”名称，卡牌可搜英文名；GitHub Pages 复用 `Jimmyzzt/AK_Exusiai` 仓库。

## 实施约束

- 上传前筛选本机能天使记录并脱敏；队友只保留人数。设置仅保留是否允许上传和打开统计网站，中英文案统一放入运行时 localization 目录；不提供删除已上传数据或刷新身份功能。
- 实时上传重试必须去重。联机统计明确按“能天使玩家局”计样本，同队多位能天使不冒充多场独立队伍局。
- 版本使用发布号和内容修订；当前 Mod 清单仍为1.1.0，统计另记 `cards-v1.3-stat-v1` 内容修订，不修改现有公开 ID。工坊发布时仍需统一发布号。
- 默认完整 Mod 组合统计；Mod 排除按“该局启用列表包含指定 Mod 就排除该局”定义，不只排除曾出现的卡牌。
- 双站发布只构建一次，记录源码内容哈希作为构建版本；跨平台发布不能保证原子切换，任一站发布失败会输出阶段状态，可重试。
- 已核对自有 `zzt.si` 域名并创建独立 `exusiai-stat` Worker/D1，绑定 `exusiai.zzt.si`。未升级套餐或改动其他服务。
