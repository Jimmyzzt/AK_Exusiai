# 能天使社区统计

[统计网站](https://exusiai.zzt.si/) · [指标说明](docs/METRICS.md)

玩家可在 Mod 设置中选择是否允许上传新增能天使对局，随时关闭。不补传玩家历史存档；仅公开聚合统计，不公开逐局数据或玩家身份。

## 功能范围

- 默认单人、标准、前三幕、排除放弃局；进阶筛选 A0–A10。
- 纳入所有 Mod 环境，继续收集环境信息；Mod 组合筛选暂不支持，使用时会明确提示。
- 只展示能天使新增卡牌、角色遗物及先古遗物。
- 卡牌支持列表/平铺、基础/升级切换、逐幕指标及悬停说明；缺失或不足样本显示“—”。
- 统计有新增数据时更新，两次换版至少间隔15分钟。
- 图表提供纵轴刻度、悬停数据点及键盘查看；范围内没有记录时不补造数据。

## 开发

目录包括 mod/ 采集代码、web/ 网页资源、shared/ 指标工具及通用回归测试。stat/ 不进入游戏资源扫描，仅显式编译 mod/ 的 C# 文件。

在 stat 目录执行：

~~~powershell
npm ci
npm run build
npm run check
npm test
~~~

卡图按项目工具提供的裁切范围生成，中英文名字、类型与描述从源码和本地化更新。授权与设置文案位于 AK_Exusiai/localization/statistics/{zhs,eng}.json，修改时保持键一致。

不要修改已发布的上传协议标识或玩家安装身份。采集逻辑仍需实战验证跨幕、升级、联机归属、离线重试及撤销授权。
