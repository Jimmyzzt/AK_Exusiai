# 统计实施说明

更新：2026-10-07。主站为 [exusiai.zzt.si](https://exusiai.zzt.si/)，镜像为 [GitHub Pages](https://jimmyzzt.github.io/AK_Exusiai/)。

## 数据流与隐私

`Entry.Initialize` 注册 `stat/mod/` 中的 RitsuLib 遥测申请和生命周期订阅。玩家授权 `run_history` 后，局终只提取本机能天使玩家的游戏已有记录。捕获过滤器拒绝框架的自动原始跑局事件；本集成不读取历史目录，不进行补传。

上传内容为局终日期（UTC）、结果、幕/层数、时长、进阶、模式、人数、游戏/Mod版本、内容修订、启用 Mod ID/版本，以及本 Mod 卡牌和遗物的归一化计数。队友只有人数，不发送卡组、网络ID、SteamID、种子、日志或框架安装/会话标识。局ID由本机随机凭证对局身份做 HMAC，服务器只保存脱敏记录和凭证哈希；Cloudflare 接收网络请求时仍会处理 IP 等连接信息。

RitsuLib 管理授权与有界磁盘队列。适配器逐局发送，数据库事务成功后确认，临时错误保留并重试；重复局ID不重复累计。每15分钟尝试刷新授权队列，重启后也可恢复。关闭授权停止后续发送，不等于删除已上传记录。

权限申请的可编辑文案在 `mod/ExusiaiTelemetry.cs` 的 `DisplayName` 与 `TelemetryRequest.Description`。服务器确认后本机日志输出 `Statistics server confirmed ...`，日志不包含凭证或跑局明细。统计注册失败只关闭此功能，不阻止角色加载。

删除凭证保存在游戏 `user://exusiai-stat-identity.txt`，队列中也有该局所属凭证，不能提交或共享。Mod 设置中的删除入口先关闭上传，再通过 URL fragment 打开确认页；网页立即从地址移除凭证，以 Bearer 请求删除。服务器删除该身份的私有记录、扣除汇总贡献并永久撤销旧身份。旧队列重传返回410；生成新身份前由服务器验证删除成功，之后需重新授权。丢失凭证无法证明删除权限。已有边缘缓存最多约15分钟后更新。

## 指标与筛选

统计单位为“能天使玩家局”：联机队伍有多名能天使时，各自授权上传算各自样本。默认单人标准局、全部 Mod 组合、排除放弃局；可将放弃计作失败，或查看联机、每日挑战、自定义模式。Mod 排除是排除启用了任一所选 Mod 的整局，最多同时10项。

| 指标 | 分子 / 分母 |
| --- | --- |
| 通关率 | 通关玩家局 / 纳入玩家局 |
| 奖励选取率 | 选择次数 / 提供次数 |
| 第X幕选取率 | 第X幕选择次数 / 第X幕提供次数 |
| 第X幕选择后通关率 | 在该幕选过此牌且通关的玩家局 / 在该幕选过此牌的玩家局 |
| 持有率 | 局终持有此物的玩家局 / 纳入玩家局 |
| 持有胜率 | 局终持有此物且通关的玩家局 / 局终持有此物的玩家局 |
| 平均获得层数 | 获得层数总和 / 获得次数 |

同局同幕重复选同牌，选择后通关率只计一个玩家局；选取率仍按次数计算。零分母显示“—”，胜率样本不足30局标记低样本。指标是相关性，不能单独证明卡牌强弱。

内容目录由源码和中英本地化生成：105张卡牌、9件角色遗物、20件先古遗物，不纳入原版/其他 Mod 内容。卡牌获得、升级、删除沿用逐层记录，初始牌不冒充奖励样本。遗物永久持有排除中转副本；获得次数按 ID/层数合并最终栏、选项和购买来源，取来源最大次数以避免重复。游戏记录缺失、同层同ID来自多个独立来源或赠送后已失去时，获得数据可能低估；首版没有新增玩法埋点。

当前 Mod 清单保持1.1.0，内容修订为 `cards-v1.3-stat-v1`，两者可独立筛选。改变统计口径或内容后更新修订，不追溯改写旧记录。

## API 与数据库

| 路径 | 用途 |
| --- | --- |
| `POST /api/upload` | Bearer 本机凭证；严格校验 `exusiai.run.v1` 脱敏单局DTO，落库/去重后确认 |
| `GET /api/stats` | 公开 `exusiai.statistics.v1` 聚合，支持筛选，无逐局或玩家标识 |
| `GET /api/health` | 服务信息、上传开关；不等于数据库就绪探针 |
| `POST /api/delete` | Bearer + `{"confirm":"delete-my-statistics"}`，事务删除并撤销身份 |
| `GET /api/identity` | Bearer 查询自己的撤销状态，仅返回 `revoked` |

筛选参数：`party=solo|multi|all`、`mode=Standard|Daily|Custom|all`、`abandoned=exclude|loss`、`from/to=YYYY-MM-DD`、`version`、`revision`、`ascension`、可重复 `exclude=ModID`。公开 CSV 同样只有当前筛选的聚合指标。

`runs/entities` 保存私有计数用于删除与复核；`cohorts/cohort_entities/cohort_mods` 按日期、版本、进阶、人数、模式、放弃及 Mod 组合预聚合，查询不扫描每局原始JSON。上传与删除使用 D1 原子批次；写入随机 nonce 避免并发重试混入不同负载。`revoked_owners` 阻止已删除身份重传。

查询快照有效期15分钟，默认查询由定时触发刷新，其他筛选首次访问生成。快照缓存最多128项，淘汰查询缓存不删除对局。D1/边缘/浏览器旧快照为临时故障提供回退；无已有缓存时明确显示不可用。客户端单次128KiB上限、IP每分钟30次、每身份每日最多30局限制用于控制误用；公开 Mod 客户端无法提供不可伪造的反作弊证明，后续异常数据需要维护者复核。

网页刷新只重新请求当前筛选，不强制清缓存或重算。命中边缘快照不读D1；冷边缘先读取D1的一条快照，15分钟内仍复用。筛选首次访问或快照到期才聚合计算。标准进阶筛选仅 A0–A10；上传端仍保留扩展数值范围，避免因其他 Mod 改进阶上限而拒收整局。

所有记录暂不设到期时间，未启用自动删除或付费服务。免费写入/请求配额或存储容量耗尽会导致接收失败，客户端队列有限；满库需要维护者决定处理办法。`UPLOAD_ENABLED=false` 可主动暂停上传。当前查询缓存不能替代永久离线备份。

## 构建与部署

依赖用 `npm ci` 复现；`npm run build` 生成目录与自有图片到 `dist/`。Node依赖、网页和统计测试均通过 `.gdignore`、PCK排除和项目编译项隔离于游戏资源；只有 `mod/**/*.cs` 加入 Mod 编译。禁止把 RitsuLib 或网站依赖打进游戏包。

当前编译/运行时基线为 RitsuLib0.6.6。主项目和测试项目均禁用自动复制，仓库 `Directory.Build.targets` 统一落实该限制并拒绝命令行强行开启；测试也使用NuGet编译引用和工坊运行时，不创建游戏本地副本。

首次环境需要 Cloudflare 登录、免费账户中的 D1 和 GitHub 仓库发布权限。当前 `worker/wrangler.jsonc` 已绑定本项目新建的 `exusiai-stat` 数据库、Worker、自有域名与每15分钟定时触发。新账户使用时替换账户/数据库ID和路由；不要重用其他项目数据库。迁移已发布后追加新迁移，勿修改已应用文件。

`npm run publish` 依次执行一次构建、类型检查、Worker/D1测试、dry-run、远程迁移、Worker发布及 `gh-pages` 发布。两站收到相同构建；构建ID按代码内容计算，`build.json` 同时记录构建时间和基线提交。Pages独立构建有延迟，不保证原子切换。发布失败保留已成功服务并记录阶段，可修复后重试。发布不提交或推送源码分支，也不发布创意工坊包。

本地：先 `npm run build`、`npm run migrate:local`，再 `npm run dev`。发布或重建前停止开发服务器，避免 Windows 文件锁。`STAT_API_ORIGIN` 只用于本地前端调试；双站发布脚本会固定恢复生产API。生成的类型用 `npm run types` 更新，不手写环境接口。

## 验证与待验收

已完成：Mod纯C#和完整构建/PCK导出0警告0错误，提取测试覆盖本机归属、幕数、脱敏ID、放弃、先古选项去重；上传适配器测试覆盖授权、撤销、部分批次重试、凭证/信封脱敏、旧身份、限流与断网。6项真实 Miniflare/D1 测试覆盖15分钟缓存、去重、筛选、删除与撤销、失败回滚和并发重试。线上站点/API已访问，生产数据库未写入构造测试局。

仍需玩家在游戏中启用本机 Mod，用备用局验收：

1. 未授权结束一局不产生上传；授权后新的单人能天使局、放弃局正常累计，其他角色不上传。
2. 联机仅上传本机能天使记录，队友选择不计入；保存重载后能辨认本机玩家。
3. 断网局终后恢复连接/重启可重试且仅计一次；关闭授权时队列不再发送。
4. 卡牌各幕选择及遗物快递/中转与网站口径一致。
5. 删除后汇总减少、旧队列不可重传，验证删除后新身份需重新授权。
