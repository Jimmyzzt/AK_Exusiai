采集范围

玩家在 RitsuLib 中明确授权后，仅采集新结束的本机能天使对局；不扫描历史存档。包含单人、联机、失败与放弃局。记录局终结果、日期、进阶、幕数、版本、启用 Mod，以及本 Mod 的卡牌与遗物计数。默认统计单人标准局、全部 Mod 组合，排除放弃局。

上传前剔除 Steam / 网络玩家 ID、玩家名称、种子、队友明细、日志和本地路径。服务保存脱敏记录和安装凭证的单向摘要，以便去重和删除。原始逐局记录及安装标识没有公开查询接口；页面与导出仅提供汇总。Cloudflare 处理请求所需的网络元数据；应用不记录上传内容或凭证。

指标如何计算

样本单位为“能天使玩家局”；同一联机队伍的两位能天使各自授权后贡献两份玩家样本。胜利以游戏局终标记为准，放弃计作失败时强制视为失败。

  • 奖励选取率 = 选择次数 / 提供次数。同牌重复提供按次数统计。
  • 持有率 = 局终卡组或永久遗物栏持有该内容的玩家局 / 总玩家局；每局每内容计一次。
  • 持有胜率 = 持有该内容的通关玩家局 / 持有该内容的玩家局。
  • 第X幕选择后通关率 = 在第X幕选择过该牌且最终通关的玩家局 / 在第X幕选择过该牌的玩家局；同局同幕重复选择只计一次。
  • 卡牌平均获得层数由逐层获得记录计算；升级和删除为历史记录次数。初始牌无获得事件时显示不适用。
  • 遗物获得次数结合逐层选取、先古选择、购买及最终永久栏记录。同ID同层的多种来源取最大次数，避免重复记录；这可能保守低估特殊Mod在同层反复获取的情况。中转副本不计入永久持有，先古选项按记录中的选项键匹配本 Mod 遗物。

没有分母时显示“—”；低样本应谨慎解读。最终持有胜率和获得后通关率均受生存、选牌与玩家水平影响，不直接代表平衡强度。首版没有战斗出牌与伤害统计。

更新和保存

统计约每15分钟刷新。当前不设记录保存期限，也不自动清理对局数据。使用 D1 和 Workers 免费档位；遇到配额或连接问题时客户端保留有限队列等待重试，页面尽量显示最近成功的统计。首次访问且无缓存时会明确提示暂不可用。

上传授权

是否允许上传由 RitsuLib 遥测授权控制，可在游戏 Mod 设置中随时关闭。只收集开启上传后结束的新对局，不补传历史存档。
