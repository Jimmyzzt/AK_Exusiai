采集范围

玩家在 RitsuLib 中明确授权后，仅上传新结束的本机能天使对局，不扫描历史存档。包括结果、日期、进阶、版本、启用 Mod 及其公开工坊 ID，以及能天使卡牌、遗物的逐幕获得与选取摘要、幕末持有摘要、战斗损血和回合数。

上传前剔除 Steam / 网络玩家 ID、玩家名称、种子、队友明细、日志和本地路径。安装凭证仅保存单向摘要用于去重。原始逐局记录和安装标识没有公开查询接口；页面与导出仅提供聚合统计。Cloudflare 处理请求所需的网络元数据；应用不记录上传内容或凭证。

幕数与胜利

默认观察前三幕，完成第三幕即视为通关，后续额外幕的失败或放弃不影响此结果。选“所有幕”时采用完整对局结果。单幕筛选只观察该幕的选牌与获得，通关仍以第三幕为终点。幕末持有率采用选定范围终点的卡组和永久遗物栏。旧对局中无法确认第三幕结果、持有状态或获得层数的样本，不进入相应指标的分母。

如何读这些指标

指标名称悬停可查看定义。WAR / pWAR 使用选牌前的玩家水平与楼层基线估计预期胜率，分别累计所有提供 / 实际选取的“实际胜利减去预期胜利”。本站采用固定漂移的个人模型与历史楼层基线，未完全复现 Spirebird 的模型校准。后期偏好是选取率随总层数的变化，未采用参考站的 Elo 残差。损血与回合变化使用同进阶、人数、模式、幕数、遭遇的历史战斗均值；这些相关指标不能解释为卡牌的因果贡献。

新采集版本支持升级版和战斗指标；旧数据继续贡献其可计算的指标。无样本或覆盖不足显示“—”，不推测补值。pWAR% 至少10次选取；损血与回合变化至少10个选取玩家局，战斗基线至少5场；后期趋势至少20次提供。低于30个相关样本标记小样本。

Mod 标签

只接受 Steam 的官方分类标签，忽略自定义标签。主要标签按角色、幕数、内容扩展、工具依赖、QoL、视觉、音频、其他的优先级确定；无法准确匹配工坊条目或没有官方标签时显示“无标签”。每15分钟处理有限批次，优先新出现的 Mod；每个条目每天重新查询一次。大批积压期间全库轮询可能超过一天。支持全部 Mod 的单项排除，及常用名单内的双项交集；未覆盖的组合会明确提示不支持。

更新、保存与授权

公开统计由后台维护并约每15分钟发布到 GitHub Pages。筛选在浏览器本地计算；刷新只检查公开版本，不触发数据库重算。当前不设记录保存期限，使用 D1 和 Workers 免费档位；遇到配额或连接问题时保留上传队列重试，页面继续显示最近成功的公开版本。可随时在游戏 Mod 设置中关闭上传。
