# 能天使卡牌特效与音效管理器

独立 Godot 窗口负责选择、编辑和保存；原版特效与声音在正在运行的游戏中试播。窗口中央是发射位置示意图，不是实际特效预览。无需制作新的人物动画。

## 启动

在项目根目录配置好 `local.props` 中的 `GodotExe`，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\card_effect_manager\run_card_effect_manager.ps1
```

首次使用游戏内试播前，需要退出游戏并完整构建一次 Mod：`dotnet build .\AK_Exusiai.csproj`。随后启动游戏，在能天使的单人战斗中按反引号打开控制台，输入 `exusiai fx on`。管理器会显示连接状态和当前敌人列表。`exusiai fx off` 关闭开发覆盖；退出战斗也会自动关闭。

## 常用操作

1. 右侧选择能天使卡牌，名称显示类型与关联预设，例如 `天赋 · 能力（天使buff通用）`。普通版和升级版始终共用一套效果。
2. 左侧按中文卡名（例如“超能光束”“华丽收场”）、英文卡名或资源名搜索。选择组合预设后点“应用所选”；单个特效或音效通过“命中位置 / 出手位置”选择覆盖位置。
3. 点击“试播当前卡牌效果 · F5”，或在管理器 / 游戏窗口按 **F5**。管理器自动准备当前卡牌配置、目标和段数；切到游戏后按 F5 即可重复试播，不必切回管理器。游戏需先启用 `exusiai fx on`。可选择单个敌人、全部敌人或自身；试播不结算伤害、消耗弹药或执行原卡玩法。
4. 在中央拖动蓝色发射点，或填写 X/Y；可为六套已有外观分别存偏移。外观下拉框选择的是正在编辑的配置，不切换游戏角色。原生 Creature 工厂的效果会在详情中注明偏移限制。
5. 编辑会自动保存并向已启用的游戏发送开发覆盖。用真实卡牌确认伤害段数、目标和音画时序后，再“导出当前 / 全部”，按正常流程构建发布。

卡图下方的“组合预设”可直接选择原版或自建预设。“另存为预设”创建新预设并关联当前卡；“修改名称”更名但保留稳定引用。关联后编辑参数（包括偏移）会同步到所有关联卡，界面显示影响张数；只想单独调整时，先“解除关联”。批量应用关联预设时也建立共享引用。复制 / 粘贴传递参数；粘贴到关联卡会修改其共享预设。撤销 / 重做包含全部共享修改，恢复默认只删除当前卡的绑定。

五套通用技能 / 能力预设可搜索“通用”：增益、格挡、治疗、减益、能力启动。前三项和能力启动把特效放在施法者位置；减益显示在目标位置。它们复用原版一次性素材，不调用原卡玩法，也不要求新增人物动画。

出手特效 / 音效、命中特效 / 音效分别左右并列，延迟与独立音量并列；所有按钮与下拉框有细边框。大倍率或小屏幕下可滚动整个窗口，右侧配置也可独立滚动。

“沿用当前 / 预设”保留相应默认效果，“无”明确关闭该独立通道。预设自带的声音及震屏仍由原版节点控制；独立音量只调节额外选择的音效。试播停止会移除本工具持有的节点；已交给原版音频系统的一次性声音会自然结束。

## 覆盖与验证状态

目录基于本机游戏程序集及 PCK 的源引用、场景依赖、临时音频清单重建。精确统计与每个原版攻击来源的结果在 `catalog_audit.json`。`adapted` 表示已实现适配，不表示已经在游戏里逐项验证。

- `○`：可绑定，待本机实测。
- `✓`：用户试播左侧素材完成后手动确认，且游戏目录指纹匹配。
- `△`：已发现但未适配，或原卡没有独立演出。开启“显示待适配”查看原因及关联素材。

默认过滤 UI 提示音等其他来源；切到“所有来源”可以检索。循环及环境音保留为候选，避免一次性播放接口产生无法停止的循环声音。怪物整套招式依赖专用角色状态的部分保留候选，其中可复用的独立节点和声音仍可选择。

不复制游戏 DLL、PCK、音频 bank 或整套美术。FMOD 条目来自代码和场景引用，不能据此声称已穷举全部 bank。游戏更新后必须重建目录、重新构建 Mod，并复查原有验证记录。

## 文件与开发检查

### 自定义音效（目前需要登记目录）

运行时可播放 Mod 内的 `AudioStream` 文件，但管理器尚无拖入文件或自动扫描外部音频功能。建议把短促换弹声剪去首尾静音，保存成不循环的 WAV；OGG 也可作为运行时音频。文件放在项目资源目录，例如 `AK_Exusiai/audio/card_effects/reload_rifle.wav`。

在 `tools/card_effect_manager/custom_audio.json` 的 `entries` 中登记一次，示例：

```json
{
  "id": "custom:reload_rifle",
  "name": "步枪换弹",
  "file": "AK_Exusiai/audio/card_effects/reload_rifle.wav"
}
```

在项目根目录运行 `node tools/card_effect_manager/custom_audio.mjs`，将自定义登记同步到 `AK_Exusiai/config/card_effect_catalog.json`；不必重新反编译游戏。`rebuild_catalog.ps1` 也会读取这份独立清单，重建原版目录不会丢失自定义登记。仅复制文件并点“重新扫描”不会自动登记。支持 WAV、OGG、MP3；登记会校验路径、文件存在性和重复 ID。

登记并完成 Godot 导入 / Mod 完整构建后，重启游戏和管理器，在“出手音效”选择该音效；换弹类技能可用“非攻击牌：出牌开始”。把它保存成共享“换弹通用”预设，再批量关联换弹卡即可。新文件首次加入需要构建进入 PCK；之后调音量和卡牌绑定可用开发热重载试播。保留作者、下载链接与许可记录，提交公开仓库前确认许可允许分发音频源文件。

已登记 `custom:mag_insert`（换弹 · 插入弹匣），已建立“换弹通用”共享预设：双发套件、爆弹、能天使、圣城净化、并联弹匣、压满弹匣！、子弹上膛、回望来路、快速弹匣。出牌开始播放一次独立音效，音量 1，初始不加特效或人物动作，可在管理器中统一调整。按用户确认保留“勿忘我”的攻击配置；不加入后续触发补弹的子弹之约、帕格尼尼改装。这里只设置出牌演出，不额外监听实际弹药变化，因此 0 填弹量 / 过载阻止获得时仍可播放，延迟获得弹药也不会再次播放。

| 文件 | 用途 |
| --- | --- |
| `card_effect_manifest.json` | schema 2 编辑清单、共享预设引用、收藏和本机试播确认 |
| `../../AK_Exusiai/config/card_effects.json` | 导出的正式卡牌绑定，随 PCK 发布 |
| `../../AK_Exusiai/config/card_effect_catalog.json` | 去重效果目录与组合预设 |
| `catalog_audit.json` | 原版攻击来源覆盖和限制 |
| 游戏用户目录下 `AK_Exusiai/card_effect_manager/` | 请求、状态、临时开发覆盖及资源检查结果 |

Windows 默认桥接位置为 `%APPDATA%/SlayTheSpire2/AK_Exusiai/card_effect_manager`。这是游戏的自定义用户目录，与 Godot 管理器自身的 `user://` 不同。自定义环境可直接启动场景并传 `-- --bridge-dir=<路径>`。开发覆盖只在手动启用后的单人战斗生效；联机使用正式发布配置。

旧清单首次打开时备份为 `card_effect_manifest.json.v1.bak`，随后迁移：普通配置为准，移除升级区分；与旧个人预设完全一致且只有一个匹配的卡牌自动关联，其他独立配置保留。编辑清单通过 `preset_ref` 引用稳定 ID，`presets` 保存名称和参数。正式导出与热重载会展开为 schema 1 的 `base` 配置，运行时忽略旧 `upgrade` 字段。“导出当前”也刷新此前已导出的卡牌，使共享修改全部同步；其他未导出卡仍不发布。发布仍需正常构建。

`prepared_preview.json` 保存最近选择，用于游戏 F5；`request.json` 为按钮请求。F5 不会重放上一次按钮命令，也不依赖操作系统全局热键。管理器关闭后保留最后准备的配置；关闭 `exusiai fx` 或退出战斗后 F5 不再触发本工具。

启动脚本也支持 `-BridgeDirectory <路径>`。运行时比对实际游戏 DLL 指纹；不匹配时保持原有卡牌表现并拒绝试播，重建目录和 Mod 后恢复。未配置卡牌无需迁移。

```powershell
# 无窗口验证 UI、卡牌扫描、绑定、撤销和校验
.\tools\card_effect_manager\run_card_effect_manager.ps1 -SmokeTest

# 先完成一次 Debug 构建，再同时验证 Godot JSON 与真实 C# 配置读取
.\tools\card_effect_manager\run_card_effect_manager.ps1 -ContractTest

# 重新反编译当前安装程序集并重建目录；路径通过本机参数传入
.\tools\card_effect_manager\rebuild_catalog.ps1 -IlspyExe <ilspycmd.exe路径>

# 仅在现有反编译目录指纹匹配时复用
.\tools\card_effect_manager\rebuild_catalog.ps1 -UseExistingSource
```

“检查游戏资源”验证当前游戏能否找到场景及临时音频；音频事件存在性和实际视觉仍需试播确认。真实出牌验收至少覆盖单段、多段、AOE、随机目标、击杀中断、基础/升级、技能/能力以及结束战斗清理。
